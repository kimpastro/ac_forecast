# AC Forecast

It get's the weather based on an address or a zipcode.

## How to run locally

### With docker

Steps:

1. Run: `docker compose up`
2. Access: `http://localhost:3000` in your browser.

### Without docker

Steps:

1. Run `bundle install`
2. Run `bin/dev`
3. Access `http://localhost:3000` in your browser.
